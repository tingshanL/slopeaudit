# Restricted AABC2 data

This directory contains access instructions only. AABC2 participant-level data,
derived participant rows, rosters, exact visit schedules, and identifier-linked
results are not distributed with the package.

Qualified researchers must register with BALSA, agree to the current AABC Data Use Terms, and obtain AABC Release 2 through the official access route:

- https://www.humanconnectome.org/study/hcp-lifespan-aging/document/aging-adult-brain-connectome-release-2
- https://balsa.wustl.edu/project?project=AABC2

The analysis scripts accept explicit local paths from authorized users and omit
those paths from logs and manifests.
