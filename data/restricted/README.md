# Restricted AABC2 data

No AABC2 participant-level data, derived participant rows, rosters, exact visit schedules, or identifier-linked results belong in this repository.

Qualified researchers must register with BALSA, agree to the current AABC Data Use Terms, and obtain AABC Release 2 through the official access route:

- https://www.humanconnectome.org/study/hcp-lifespan-aging/document/aging-adult-brain-connectome-release-2
- https://balsa.wustl.edu/project?project=AABC2

The analysis scripts read local paths supplied explicitly by the authorized user. Those paths and files are never searched for recursively and are never written to logs or manifests.
