# Private v12 pilot provenance stub

The audited v12 repeated-pilot checkpoint and associated tables are
**restricted-derived provenance** because the pilot used the exact
AABC2-derived irregular schedule. They are not distributed in the public
repository.

Authorized internal reproduction of nested-bootstrap `pilot` mode may point
`SLOPEAUDIT_Q1_NESTED_BOOTSTRAP_V12_PILOT_INPUT` to the private byte-preserved
directory. The same workflow also requires `SLOPEAUDIT_Q1_V11_EVIDENCE_DIR`
and `SLOPEAUDIT_Q1_IRREGULAR_SCHEDULE`.

The public repository retains deterministic synthetic/public-data checks and
protocol documentation; it does not expose this restricted-derived checkpoint.
